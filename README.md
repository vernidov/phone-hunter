# Phone Hunter — локальный OSINT-инструмент по номеру телефона

**Phone Hunter** — это веб-приложение для поиска и сбора информации по номеру телефона.  
Проект полностью локальный, не требует подключения к внешним сервисам (Telegram, Render и т.п.) и может быть запущен на вашем компьютере или сервере.

![Интерфейс](https://via.placeholder.com/800x400?text=Phone+Hunter+UI) <!-- Замените на реальный скриншот, если есть -->

---

## 🚀 Возможности

- 🔍 Поиск информации по номеру телефона (OSINT)
- 🌐 Локальный веб-интерфейс на HTML/CSS/JS
- ⚡ API на Python (FastAPI) для обработки запросов
- 🛠️ Гибкая архитектура: легко добавлять новые источники данных
- 🔒 Всё работает офлайн — данные не уходят на сторонние сервера
- 📦 Поддержка форматов номеров с кодом страны

---

## 📋 Требования

- Python 3.8+
- Установленный менеджер пакетов `pip`
- Браузер (для доступа к веб-интерфейсу)
