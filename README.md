# Phone Hunter — локальный OSINT-инструмент по номеру телефона

**Phone Hunter** — это веб-приложение для поиска и сбора информации по номеру телефона.  
Проект полностью локальный, не требует подключения к внешним сервисам (Telegram, Render и т.п.) и может быть запущен на вашем компьютере или сервере.

![Интерфейс](https://via.placeholder.com/800x400?text=Phone+Hunter+UI) <!-- Замените на реальный скриншот, если есть -->

---

## 🚀 Возможности

- 🔍 Поиск информации по номеру телефона (OSINT)
- 🌐 Локальный веб-интерфейс на HTML/CSS/JS
- ⚡ API на Python (FastAPI) для обработки запросов
- 🛠️ Гибкая архитектура: легко добавлять новые источники данных
- 🔒 Всё работает офлайн — данные не уходят на сторонние сервера
- 📦 Поддержка форматов номеров с кодом страны

---

## 📋 Требования

- Python 3.8+
- Установленный менеджер пакетов `pip`
- Браузер (для доступа к веб-интерфейсу)

## ⚙️ Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/vernidov/phone-hunter.git
cd phone-hunter

2. Настройка бэкенда

Перейдите в папку backend и установите зависимости:
bash

cd backend
pip install -r requirements.txt

Запустите сервер API:
bash

python main.py

По умолчанию сервер запустится на http://localhost:8000.
Вы можете изменить порт в настройках.
3. Запуск фронтенда

Откройте файл frontend/index.html в любом браузере.
Если вы используете локальный сервер, можно открыть через http://localhost:8000 (если настроена раздача статики).
🧪 Использование

    Введите номер телефона в формате с кодом страны (например, +71234567890).

    Нажмите кнопку «Поиск».

    Результаты отобразятся на странице — вы увидите:

        Страну и регион

        Оператора

        Возможные социальные профили (если доступны)

        Дополнительную информацию из открытых источников

    ⚠️ Важно: Используйте инструмент только для легальных целей (например, проверка собственных номеров или работа с согласием владельца). Автор не несёт ответственности за неправомерное использование.
